# 🔎 Wireshark Network Traffic Analysis Lab

## 📌 Overview

This project documents my hands-on practice with **Wireshark** while learning network traffic analysis and cybersecurity fundamentals.

The goal of this lab is to understand how devices communicate across a network by capturing and analyzing packets, identifying protocols, examining source and destination addresses, and using Wireshark filters to investigate network traffic.

> This repository is part of my cybersecurity learning journey and documents practical labs completed during my training.

---

## 🎯 Objectives

- Capture and inspect network traffic
- Understand how packets travel across a network
- Identify source and destination IP addresses
- Identify network protocols
- Examine packet information using Wireshark
- Practice filtering network traffic
- Develop practical network-analysis skills
